# Telegram-бот для оформления постов

Бот построен на aiogram 3. Он последовательно спрашивает название, описание, теги, версию, описание мода и картинку. Кнопки «Назад», «Отмена» и «Начать заново» доступны на этапах заполнения.

## Оформление

- Название — с премиум-эмодзи.
- Описание — курсивом и с эмодзи огня.
- Теги и версия — вместе в цитате.
- Строка «Мод: …» — целиком жирным.
- Текст и картинка отправляются в одном сообщении, текст расположен над картинкой.

Для пересылки нажмите кнопку под постом, выберите чат и отправьте предложенный готовый пост. В Bot API это задаётся параметром `show_caption_above_media`.

## Подготовка

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Включите inline mode командой `/setinline` в BotFather и задайте короткую подсказку, например `Выберите готовый пост`.
3. Скопируйте `.env.example` в `.env`, укажите токен бота и свой числовой Telegram ID.
4. Установите зависимости и запустите из этой папки в PowerShell:

```powershell
python -m pip install -r requirements.txt
python .\bot.py
```

Узнать свой числовой Telegram ID можно у бота вроде `@userinfobot`.

При первом открытии бота нажмите стандартную кнопку Telegram «Начать», затем «Создать пост». Команды для управления черновиком не нужны.

Черновики хранятся в памяти и очищаются при перезапуске бота. Доступ разрешён только ID из `ALLOWED_USER_IDS`.
